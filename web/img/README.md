## 为什么放在本地

项目原则是「低端机与弱网友好、断网可用」，所以不引用 CDN，
全部静态文件存于本目录。总计约 236 KB（6 张 PNG）。

## 对应关系

| 文件 | 原素材 | 用在哪 |

| `seedling.png` | Seedling | 登录页、行动台账、学生问卷页 |
| `sun.png` | Sun | 班级概览、全校心理态势 |

## 替换原则

插图只做视觉点缀，不承载信息——任何一张图删掉，页面功能与语义都不受影响。
若需替换，保持 3:2 或 1:1 比例、透明底、主体居中即可。
