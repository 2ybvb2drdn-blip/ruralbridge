## 一、项目介绍

### 1.1 我们解决的问题

乡村学校心理健康教育资源极度匮乏：专职心理教师配备率低，大量乡村学校由班主任兼管心理健康工作。班主任既缺乏专业评估工具，也难以察觉留守儿童中"隐性"的心理问题——这些学生往往外表安静、成绩平稳，风险信号只存在于日常行为的细微变化里，等被发现时常常已发展为中重度问题。

现有心理测评产品多为"量表测评—生成报告"的单一链路，存在三个短板：

1. **学生配合度低**：需要独立完成长量表，乡村学生易敷衍作答；
2. **无法动态跟踪**：一学期测一次，两次测评之间是盲区；
3. **报告不可执行**：给出的是"给人看的分数"，不是"给老师用的行动方案"。

### 1.2 我们的方案

**乡育心桥**是一个专为乡村教师设计的 Web 应用。它以**轻量化心理问卷**与**多模态日常记录**为双数据入口，由 AI Agent 自动完成"数据采集 → 心理评估 → 理论检索 → 干预方案生成"的完整闭环，输出的不是分数，而是**班级心理晴雨表**与**可直接执行的学生个体干预方案**。

| 层次 | 输入 | AI 处理 | 输出（给班主任用） |
|---|---|---|---|
| 个体层 | 微问卷 + 课堂观察速记 + 家校沟通记录 | 识别风险信号、匹配心理学理论、生成分步干预建议 | 个体干预方案卡（含沟通话术、观察指标、转介建议） |
| 班级层 | 全班问卷聚合 + 出勤/作业/互动等行为数据 | 聚类风险分布、识别群体性诱因 | 班级心理晴雨表（绿/黄/红三色 + 趋势） |
| 学校层 | 跨班级聚合数据 | 生成学校心理工作重点建议 | 校级心理工作月报 |

### 1.3 核心创新点

**应用创新点**

- **场景创新**：切入"乡村教育 × 教师辅助"的交叉空白地带，不做面向学生的心理 App，而做面向班主任的**决策辅助工具**，把 AI 的定位从"测评机器"改为"有心理学理论支撑的教研助手"。
- **闭环创新**：打通"采集—评估—理论—干预"四段链路。干预建议不是大模型凭空生成，而是先检索专业心理学理论，再结合学生个体数据生成，做到**有据可查、可追溯到理论来源**。
- **低负担设计**：问卷单次填写控制在 3 分钟以内，配合多模态日常记录，用"高频轻量"替代"低频重负"，使动态跟踪成为可能。

**技术创新点**

- **多模态数据融合**：将结构化问卷数据与非结构化文本记录统一向量化，进入同一检索空间进行风险推理。
- **RAG + 规则双引擎**：心理风险识别采用"规则引擎兜底（高危信号必须硬触发）+ 大模型语义推理"的双通道，避免纯 LLM 方案在高危场景下的漏报。
- **理论可溯源**：每条干预建议携带来源理论标签与引用片段，教师可展开查看理论依据，解决 AI 建议"不可信、不敢用"的问题。

## 二、技术架构

### 2.1 总体架构

```
┌──────────────────────────────────────────────────────────┐
│  表现层   教师端 Web（原生 JS + 纯 CSS + SVG 图表）        │
│           无框架依赖 · 弱网/低端机可用 · 移动端适配         │
├──────────────────────────────────────────────────────────┤
│  应用层   业务逻辑（账号权限 / 名单 / 问卷 / 记录 / 报表）   │
│           演示环境：浏览器内运行                            │
│           线上环境：Serverless 函数（/api/*）               │
├──────────────────────────────────────────────────────────┤
│  AI 智能层 ① 规则引擎（高危硬兜底）                         │
│            ② 语义推理（大模型 API）                         │
│            ③ RAG 检索（向量化 + 理论库）                    │
│            ④ 方案生成（结构化输出 + 理论回填）               │
├──────────────────────────────────────────────────────────┤
│  数据层   演示环境：静态脱敏数据                            │
│           线上环境：云数据库 + 向量库 + 对象存储             │
└──────────────────────────────────────────────────────────┘
```

### 2.2 AI Agent 工作流（核心）

```
学生数据（问卷 + 日常记录）
        │
        ▼
  ① 规则引擎硬筛查 ──命中高危──▶ 直接升级红色预警 + 提示转介
        │（未命中）
        ▼
  ② 特征归一化（结构化 + 非结构化统一向量化）
        │
        ▼
  ③ 大模型语义推理（风险等级 / 风险类型 / 证据句）
        │
        ▼
  ④ RAG 理论检索（按风险类型召回心理学理论 Top-K）
        │
        ▼
  ⑤ 干预方案生成（分步建议 + 沟通话术 + 观察指标 + 理论引用回填）
        │
        ▼
  ⑥ 结果落库 → 刷新班级晴雨表 → 推送班主任
```

**关键设计**：规则引擎与语义推理**并行**，任一通道触发高危即升级风险等级，**规则通道优先级最高**，确保 AI 的不确定性不会导致漏报。

## 四、安装运行指南

### 4.1 环境要求

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge / Safari 近两年版本；移动端浏览器可用 |
| 本地预览 | 任意静态服务器（Python 3 或 Node.js 即可） |
| 线上部署 | 任意静态托管平台（本项目演示使用 Cloudflare Pages / Vercel） |
| 后端（可选） | Node.js 18+（用于 Serverless 函数转发大模型 API） |

> 演示站为**纯静态页面，零依赖、无需构建**，克隆下来即可运行。

### 4.2 本地运行

```bash
# 方式一：Python 内置服务器
cd web
python3 -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899

# 方式二：Node.js
npx serve web -l 8899
```

### 4.3 部署到公网

**Cloudflare Pages（推荐，免费、无需备案）**

```bash
npm i -g wrangler
wrangler login
wrangler pages deploy web --project-name ruralbridge
```

**Vercel**

```bash
npm i -g vercel
vercel deploy web --prod
```

**Netlify**

```bash
npm i -g netlify-cli
netlify deploy --dir=web --prod
```

部署完成后会得到一个公网地址（如 `https://ruralbridge.pages.dev`），评审期间保持可用即可。

### 4.4 环境变量配置

复制 `.env.example` 为 `.env` 并填入真实值。**`.env` 已被 `.gitignore` 排除，不会进入版本库。**

| 变量 | 说明 |
|---|---|
| `AI_API_BASE` | 大模型 API 地址 |
| `AI_API_KEY` | 大模型 API 密钥（**仅服务端使用，绝不写入前端代码**） |
| `AI_MODEL` | 模型名称 |
| `EMBEDDING_MODEL` | 向量化模型 |
| `VECTOR_STORE` | 向量库类型 |

> **安全约定**：前端永远不持有 API Key。线上环境所有大模型调用统一经服务端 `/api/ai/*` 网关转发。

## 七、数据与合规声明

- 本仓库演示环境中的**全部学生数据均为脱敏模拟数据**，不含任何真实个人信息。
- 真实场景下学生心理数据属**敏感个人信息**，系统设计遵循《个人信息保护法》与未成年人个人信息保护相关规定：单独同意、最小必要采集、敏感字段加密存储、访问日志留痕、一键删除。
- AI 输出仅供参考，**不替代专业心理诊断**；涉及高危信号时须由专业人员介入。
