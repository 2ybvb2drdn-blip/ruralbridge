# 线上后端说明（Serverless 函数）

> 演示站为纯静态页面，**不依赖本目录**即可完整运行。
> 本目录说明线上环境如何把 AI 能力接上，同时保证 API Key 不暴露在前端。

## 为什么需要后端

前端若直接调用大模型 API，Key 会明文出现在浏览器里，任何人打开开发者工具都能拿到并盗用。
因此线上环境的铁律是：**所有大模型调用经服务端转发**。

```
浏览器 ──POST /api/ai/assess──▶ Serverless 函数 ──▶ 大模型 API
                                    │
                              Key 存于环境变量
```

## 目录规划

```
server/
├── api/
│   ├── ai-assess.js      心理评估（规则引擎 + 大模型 + RAG）
│   ├── record.js         日常记录入库
│   └── export.js         报表导出
├── lib/
│   ├── rules.js          规则引擎（与前端同源，服务端复算一遍做校验）
│   └── rag.js            向量检索
└── README.md
```

## 环境变量

复制根目录 `.env.example` 为 `.env`，在部署平台（Cloudflare Pages / Vercel）的项目设置里配置同名环境变量：

| 变量 | 说明 | 是否保密 |
|---|---|---|
| `AI_API_BASE` | 大模型 API 地址 | 否 |
| `AI_API_KEY` | 大模型 API 密钥 | **是** |
| `AI_MODEL` | 模型名称 | 否 |

> 平台环境变量不会被前端代码读取，仅函数运行时可见。

## Cloudflare Pages Functions 实际实现

线上实际实现位于仓库根目录 `functions/api/ai/assess.js`（Cloudflare Pages Functions，随静态站一起部署）。

```
浏览器 ──POST /api/ai/assess──▶ Pages Function ──▶ 大模型 API
   │                                │
   └─失败自动降级─┐           AI_API_KEY 存于加密环境变量
                 ▼
          浏览器内本地引擎（规则 + 理论库）
```

函数内部处理链路（与本文档示例一致，但顺序上规则优先且会短路）：

1. **规则引擎硬筛查**（服务端复算，防止前端被篡改绕过）——命中高危则直接返回红色预警，**不调用大模型**；
2. **RAG 理论检索**——按记录文本与作答召回 Top-K 理论条目；
3. **大模型语义推理**——强制 JSON 输出（风险等级 / 类型 / 依据 / 分步建议 / 话术）；
4. **结果回填理论来源**后返回前端。

前端 `web/js/engine.js` 的 `assessAsync()` 调用该接口，**任何失败（未配密钥 / 超时 / 非 2xx / 解析失败）都会自动降级为浏览器内本地确定性引擎**，保证页面不白屏。

## 提示词要点（SYSTEM_PROMPT）

- 角色设定：乡村学校心理教师辅助工具；
- **红线约束**：禁止下医学诊断结论；不得替代专业干预；涉及自伤/自杀必须建议转介；
- 输出格式：强制 JSON Schema（level / riskType / evidence / steps / theoryRefs），便于前端渲染；
- 语言要求：面向非专业教师，使用口语化、可执行的表述。

## 降级策略

| 情况 | 处理 |
|---|---|
| 大模型 API 超时 / 不可达 | 服务端返回规则引擎结果 + 错误说明；前端捕获失败后自动降级为浏览器内本地引擎 |
| 大模型额度耗尽 | 切换到备用 API（配置第二组环境变量） |
| 向量库不可用 | 退化为关键词检索，方案仍可生成 |

> 演示站已内置上述降级逻辑的等效实现：即使完全无网络，规则引擎与理论库也能给出结构化结果。
